# C++, Clang and CMake

## What this is

A list of topics for C++, for the clang toolchain and for CMake. One line for
each topic. Two pages on each line.

The first page is the documents. It tells you the exact rule. The second page
is a tutorial. It teaches you the topic.

Read the tutorial first. Then read the documents. Then write code.

## The pages

| Name | What it is |
|---|---|
| `cppreference` | The C++ reference. The exact rule for a language feature or a library part. |
| `clang docs` | The clang and LLVM documents. Flags, sanitizers and tools. |
| `CMake docs` | The CMake reference for one command, one variable or one manual. |
| `CMake tutorial` | The official CMake tutorial, one step for each chapter. |
| `learncpp` | A full C++ course. The best start for a language topic. |
| `hacking C++` | Short pages with pictures. Good for the library and for the tools. |
| `Core Guidelines` | The rules from the C++ committee. Used where no tutorial exists. |

## Rules for this file

1. Every page address comes from the site's own list of pages.
2. Every page address is tested. A page that fails is removed.
3. One topic for each line. No levels.
